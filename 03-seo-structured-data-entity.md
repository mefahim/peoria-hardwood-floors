## Entity graph

### Organization

One canonical `Organization` node is generated by `buildOrganization()` with the stable ID `https://peoriahardwoodfloors.com/#organization`. It uses only the supplied business name, normalized phone, email, canonical website, and tagline. Address, hours, geo, social profiles, ratings, reviews, awards, memberships, certifications, affiliations, and founding date are omitted.

### WebSite

One canonical `WebSite` node is generated by `buildWebSite()` with the stable ID `https://peoriahardwoodfloors.com/#website`. Its `publisher` references the canonical Organization ID. No unsupported SearchAction was added.

### WebPage

Every indexable public marketing page and service page emits a WebPage node. Its ID is generated from the Phase 02 canonical URL, its URL is query-free and HTTPS, and it references the canonical WebSite and Organization. Page titles and descriptions are resolved from the existing Phase 02 route data or the validated service record.

### Service

Each of the six service detail pages emits exactly one Service node generated from the existing `services` records in `lib/site.ts`. Each Service references the canonical Organization as `provider` and its own WebPage as `mainEntityOfPage`. Unknown service slugs return no Service graph rather than producing fabricated schema.

### Breadcrumb

BreadcrumbList nodes are generated from the same breadcrumb labels and hrefs passed to the visible PageHero hierarchy on pages where breadcrumbs are rendered. Positions start at 1, URLs are absolute, and the service hierarchy is Home > Services > Service. No breadcrumbs are emitted for the homepage because it has no visible breadcrumb UI. No structured data is emitted for the Phase 02 noindex utility pages.

## Security review

The structured-data graph is built only from typed approved builders. There is no arbitrary JSON-LD input, arbitrary `@type`, arbitrary `@context`, graph-node injection, database access, or dashboard JSON renderer. The React serializer escapes `<`, `>`, `&`, U+2028, and U+2029 before inserting the validated graph into the JSON-LD script. The serializer test confirms that `</script>` cannot be emitted as a raw breakout sequence.
